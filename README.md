# Homebrew Tap for NNTS

Official Homebrew Tap for [NNTS](https://github.com/ellisglass/nnts) — Driverless Caps-Lock remapper, Chrome profile switcher & Copy-on-Select productivity suite for macOS in pure Swift 6.

## Installation

```bash
brew install ellisglass/tap/nnts
```

Or:

```bash
brew tap ellisglass/tap
brew install --cask nnts
```

## Update

```bash
brew upgrade nnts
```

## Uninstall

```bash
brew uninstall --zap nnts
```
